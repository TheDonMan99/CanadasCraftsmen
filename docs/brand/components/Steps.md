# Steps

The four-step "How it works" sequence. Numbered because the order matters; don't use numbers for lists that aren't a sequence.

- Provide an ordered list (`<ol class="cc-steps">`) of up to four `<li>`, each with an `<h3>` title and a one-sentence `<p>`.
- Numerals are Alfa Slab One at 48px: `brand` on light grounds, maple-bright inside `cc-band`.
- Titles are short imperatives ("Design it", "Pick it up"). The sentence answers the question a customer would ask at that step.
- Usually placed inside a `cc-band` strip. On a paper ground it works as is.
